# task

Arguments: $@

Analyze the request, inspect relevant context if needed, and clarify missing intent. Call todo view; if unfinished tasks already exist, ask whether to append or replace before changing them. Decompose each user item into concrete independently verifiable leaves, ordered in named phases by prerequisites. Use unique stable verbatim task contents; keep dependencies and strategy readable in task wording and session context. Register with todo init/append, then inspect todo view and report the actual plan. OMP automatically starts the earliest pending item; record that native behavior honestly, but do not execute it, arm timers or launch agents. Do not invent task IDs, TaskCreate or blockedBy. /babygoal is the execute-and-babysit counterpart.
