## No machine paths in the file

A checkpoint is committed, copied and read on other machines, so it holds no absolute path of this one. Write every path relative to the main folder (`lib/cli.js`, `docs/checkpoints/x.md`). Never write a drive letter (`C:\…`), a leading `/` or `\`, a `~` expanded to a home folder, a temp or cache folder, or a user name. The main folder is named by its branch alone (`### main folder [<branch>]`); a linked worktree by its folder name (the last segment of its path) and its branch. A path outside the repository becomes its last segment, or the words "outside the repository". Command output pasted into the file (`git status`, `git log`, an error) is cleaned the same way. Before writing, scan the whole text for absolute paths and rewrite each one. The path you report to the user in the chat may stay absolute.
